# Her Little Space — Flutter

Flutter companion app for **Harini's Little Space**.

It uses the same Supabase project and shared architecture as the web app:
- `shared_period_cycles`
- `shared_relationship_stats`
- `increment_shared_intimacy()`
- anonymous Supabase auth
- local mood/symptom preferences

No second Supabase project or service-role key is used.

Run:
```bash
flutter pub get
flutter run
```
